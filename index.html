Agent Diff Reviewer

paste a unified diff, surface the scary parts

Paste a unified diff (e.g. git diff output) from a Claude Code, Cursor, Aider, or any other agent run. The tool parses hunks, summarizes changes per file, surfaces patterns worth reviewing carefully (deleted security checks, new dependencies, possible secret leaks, large unexplained deletions), and renders a syntax-aware view. Browser only.
